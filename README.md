## Deskripsi
Perangkat lunak berbasis konsol dalam Bahasa C untuk manajemen logistik pengiriman barang yang menerapkan autentikasi akun, struktur data (Array Dinamis, Queue, Stack, Hash Table, BST, Graph), serta algoritma Sorting dan Searching.

## Cara Kompilasi dan Menjalankan di VS Code
1. Buka folder utama proyek ini di Visual Studio Code (`File > Open Folder...`).
2. Tekan `Ctrl + Shift + B` untuk mengompilasi proyek menggunakan GCC.
3. Buka tab **Terminal** di VS Code (`Ctrl + ` `), lalu ketik `./app.exe` (Windows) atau `./app` (Linux/Mac) untuk menjalankan program.
